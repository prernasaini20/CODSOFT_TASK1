# Number Game

## About the Project

This project is developed as part of the CodSoft Java Development Internship. It is a console-based number guessing game in which the user tries to guess a randomly generated number within a limited number of attempts.

## Features

* Generates a random number.
* Allows the user to guess the number.
* Provides hints if the guess is too high or too low.
* Tracks the number of attempts.
* Displays a message when the correct number is guessed.

## Technologies Used

* Java
* Scanner class
* Random number generation
* Loops
* Conditional statements

## How to Run

1. Install JDK on your system.

2. Download or clone this repository.

3. Open the project folder in the terminal.

4. Compile the Java program:

   javac NumberGame.java

5. Run the program:

   java NumberGame

## How to Play

1. Start the program.
2. Enter your guessed number.
3. Follow the hints displayed by the program.
4. Continue guessing until you find the correct number or run out of attempts.
